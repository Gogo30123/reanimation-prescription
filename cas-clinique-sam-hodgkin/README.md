# Cas clinique — Un choc septique chez un patient VIH

Présentation d'un cas clinique de réanimation médicale (CHU de Nîmes) : syndrome d'activation macrophagique (SAM) révélant une rechute tardive de lymphome de Hodgkin chez un patient vivant avec le VIH.

**Cas anonymisé — usage pédagogique.** Aucun nom, date de naissance, adresse, numéro de séjour ni nom de soignant ; les dates d'hospitalisation sont remplacées par des jours (J0 = admission).
